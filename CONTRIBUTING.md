# Contributing

Use the pinned toolchain and frozen lockfiles described in README. Run typecheck, lint, Vitest, xUnit and relevant browser integration tests. Keep native platform changes accompanied by actual runner/device evidence; browser tests do not demonstrate native behavior.

Make focused commits. Preserve unknown Markdown, persistent IDs and the last usable data copy. Add regression coverage for data-loss fixes. Do not weaken release gates, skip failing tests, commit signing keys, include private diary fixtures or replace published tags/assets. Dependency changes must explain security, license and compatibility effects.

Contributions to original project source are accepted under AGPL-3.0-only. Preserve upstream notices when importing third-party code. There is no transfer of rights in users' diary content. Report security issues using SECURITY.md rather than attaching personal vaults to public issues.
