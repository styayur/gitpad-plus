# GitPad+

本地优先的 Markdown 日记与笔记项目。产品愿景包括原生日历、Fluent/Material 界面、所见即所得编辑、稳定的文档/块/选区链接、Git 版本管理与插件生态。

**当前为面向 `v0.1.0-alpha.1` 的开发版本，尚未发布。** 已在本机运行 Windows 11 原生开发包及签名 Android Release 开发包。本次收尾已集成经过来源与哈希核验的 Windows x64 Win2D 源码构建包，独立保留源码和运行库条款；干净 main 对应的最终候选包验收及全部发布门禁仍待完成。Android 仅验证模拟器。不要将本开发版本作为重要笔记的唯一副本。

目前已验证 .NET 文件/SQLite 数据层、浏览器编辑器集成，以及部分原生场景：多篇日记、双编辑窗格及工作区恢复、保存重载、全文搜索、Milkdown 编辑、三秒原始源码窥视、嵌套块与选区身份、未知 Directive 保留、插件持久化、冲突归档与数据清理确认。Windows 已运行原生文件选择、位图粘贴、URI 路由和大库界面；Android 已验证模拟器上的输入、生命周期和存储。永久发布签名已按用户授权配置，密钥位于仓库外。

开发命令、架构与愿景见 [英文主页](README.md)。真实验证记录及未完成事项见 [验收报告](docs/acceptance/v0.1.0-alpha.1.md)，安装与首次使用说明见 [候选版本说明](RELEASE_NOTES.md)。Windows ZIP 未签名且仍需 WebView2；原生截图与日志保存在本地证据目录，尚未作为公开 Release 发布。浏览器测试自行启动和关闭临时服务。

Markdown 和 Sidecar 是持久数据，SQLite 可重建。外部文件变更会触发保守的恢复提示；“Check recovery” 提供当前、暂存和旧版本比较；应用选择结果前归档所有版本，并拒绝过期预览。恢复后的块/选区位置需要明确修复，不会猜测链接位置。Git 当前始终显示 `NotConfigured`，没有远端同步。

许可为 **AGPL-3.0-only**。第三方组件保持各自许可，使用者的日记内容不会仅因使用 GitPad+ 自动采用 AGPL。欢迎根据 [贡献指南](CONTRIBUTING.md)提交代码、测试与真实平台验收记录。
