# Roadmap

Before the first alpha: finish all remaining v0.1 specification gaps, qualify Windows/Android operation and IME/lifecycle behavior, audit native packages/assets, provision durable Android signing, and verify downloaded release assets. See acceptance report. These are release blockers, not deferred v0.2 features.

Later goals: v0.2 GitHub/GitLab sync, diff/history/conflicts; v0.3 timelines, backlinks/export; v0.4 graph/canvas/bases/advanced statistics; v0.5 stable plugin distribution/integrations; v1.0 cross-platform maturity. No dates promised. A provider interface does not imply remote sync is implemented.
