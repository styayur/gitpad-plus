# Data format v1

Vault/Journal/<UUIDv7>.md contains YAML frontmatter: schemaVersion, id, date (YYYY-MM-DD), title, tags, createdAt and updatedAt. Rating and richer migrations remain pending. Unknown frontmatter fields survive edits. Unmodified saves return without rewriting bytes.

Vault/.gitpad/anchors/<UUIDv7>.json contains schemaVersion, documentId, revision, contentHash (lowercase SHA-256 of the entire UTF-8 Markdown file), blocks and selections. Block IDs are UUIDv7, source offsets use UTF-16 code units in the Markdown body, and deleted IDs become tombstones. Optional `path` arrays persist nested ProseMirror child paths; older top-level-only sidecars are migrated once when edited. Heading/fold/container and nested paragraph identities are included. Undo/Redo restores the prior identity state in the editor session; undo history itself is not persisted across restarts. Selection offsets refer to rendered block text, not raw Markdown, and use normalizationVersion 1 (no Unicode normalization). Prefix/suffix and exact quote are persistent authority. Offsets are interoperable between JS strings and C# strings; byte offsets are never substituted.

A save writes new.md/new.json durably under .gitpad/transactions/<id>, retains previous copies and flushes a transaction descriptor. Same-volume renames replace Markdown then Sidecar. Startup rolls a valid pending transaction forward, verifies the resulting pair, and removes its staging directory. External-content conflicts retain both previous and staged copies and raise RecoveryRequired. Process-interruption tests cover all three checkpoints. Directory metadata fsync, full power-loss guarantees and adversarial concurrent filesystem mutations are not yet qualified across native platforms.

Deleted documents move to .gitpad/trash with a durable tombstone; startup completes interrupted trash moves. Clear-local-data also removes trash after confirmation. Assets use content-hash filenames; PNG/JPEG/GIF up to 16 MB are accepted by signature, SVG/HTML rejected. The format does not yet implement a complete hostile-image decoder policy.

The index.sqlite database contains metadata/date tables and an FTS5 title/body index. Deleted/corrupt indexes are rebuilt from validated source pairs. Settings are a replaceable JSON file. Workspace tabs/active note are saved to session.json with a monotonic sequence; startup filters deleted documents and restores the active note. Late workspace writes are rejected. E2EE is not implemented.

`.gitpad/heads/<documentId>.json` records both the Markdown and sidecar hashes so a sidecar-only external edit is also detected. Recovery inspection fingerprints every current/staged/previous version. Explicit reconciliation checks that fingerprint, archives the raw files and any open editor buffer under `.gitpad/recovery`, then saves the selected Markdown with the original document ID. Prior block IDs become tombstones; affected links require deliberate repair. A stale comparison is rejected without overwriting the newer files.

`.gitpad/plugins/<pluginId>.json` stores `schemaVersion`, `pluginVersion`, JSON `values` and named UUIDv7 `objectIds`. Storage is bounded and atomically replaced. Disable/uninstall retains it; schema mismatch fails closed rather than silently resetting values. Only an active reviewed bundle with the storage capability can use the plugin bridge. This is capability routing for trusted code, not a sandbox.

Table header/body cells retain separate nested node identities and source spans, including the editor's paragraph wrapper inside each cell. Standalone Markdown images map to image blocks. An editor-only empty block without source text uses an empty end-of-body span rather than borrowing the first paragraph's range.

Workspace state also includes an optional second distinct document ID. Both panes retain independent editor sessions and save queues. A confirmed clear first records `.gitpad-clear.json`, moves the managed Journal/Assets/metadata into a dedicated staging directory and resumes the same deletion after a crash. The ownership marker and external directories are preserved. A pending clear blocks ordinary RPC until restart completes it.
