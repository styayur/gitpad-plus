# v0.1.0-alpha.1 acceptance — release blocked

This is an unreleased development delivery, not a completed native alpha. Environment: Debian 13 x64; .NET 10.0.403; Node 24.19.0; pnpm 12.16.1; Chromium headless shell 156.0.8078.4. Native OS/device: none. User confirmed no Windows/Android acceptance environment or durable Android signing setup is available.

Verified local results: **30 xUnit tests, 38 Vitest tests, 23 Playwright integration tests, and 1 independently generated plugin test passed**, with no skipped/failed tests in these latest runs. Type checking, ESLint and Vite/SDK builds passed. npm audit after the two explicit overrides reports zero known vulnerabilities. Core NuGet vulnerability query returned no affected package entries. Portable license inventory recorded 419 restored packages, including specifically reviewed legacy xUnit license metadata. Native dependency/asset license qualification remains pending.

Actual outputs are retained in [evidence](evidence/) and [machine-readable summary](results.json). The screenshot is a real **Linux Chromium browser integration** screenshot, not Windows/Android evidence. The first [CI run](https://github.com/styayur/gitpad-plus/actions/runs/41165509112) failed on the asynchronous plugin switch and a Windows target-framework property propagating into the portable Core. Both fixes are implemented. The [second CI run](https://github.com/styayur/gitpad-plus/actions/runs/41166119095) passed portable checks and reached Windows compilation, where nullable message handling raised CS8604. That handler is fixed without disabling nullable warnings. The final [CI run](https://github.com/styayur/gitpad-plus/actions/runs/41167153299) is **successful for both portable and Windows x64 Release compilation**, at exact implementation commit `e8719718d7bf430e2d6b039f743ff0d84885bfb3`. The linked ci-run.json and CI test outputs have been downloaded and inspected. The third intermediate run was superseded/cancelled after the final anchor-safety/version batch; it is not counted as a pass.

A Linux portable storage benchmark created 1000 same-day notes: date query 20.22 ms, search 5.81 ms, rebuild 986.95 ms, 250000-UTF-16-unit document save 20.54 ms. These are one local observation, not native acceptance thresholds. The raw timestamp/runtime/memory output is retained in evidence/storage-benchmark.json.

The browser suite uses real Markdown/Sidecar/SQLite storage. It verifies create/multiple notes, Unicode editing, autosave, file reload, search, SDK toolbar unload, exact-source three-second peek, unknown block-directive retention and confirmed clear. It is not native runtime evidence. Full test outputs remain in artifacts; no device or screenshot is fabricated.

Release blockers:

- Windows 11 actual startup, create/edit/save/restart, WinUI/material/keyboard/accessibility and shutdown acceptance. Windows x64 Release compilation is verified; runtime is not.
- Android build/install/run, Chinese IME/Emoji/long-press/keyboard/lifecycle and process-death acceptance.
- Durable Android release keystore, non-debug signing, verified installable assets and repeat-download checks.
- Complete nested block/heading folding and deleted-block Undo identity coverage, live Yjs fallback integration and unambiguous repair UI.
- External Markdown/sidecar reconciliation UI, complete native multi-pane workspace (tab/active-note restoration is implemented).
- Complete persistent plugin storage/object identity. A separately generated and compiled plugin has passed actual PluginHost registration/execution/unload without Core edits.
- Unsupported inline/HTML extensions remain conservatively read-only or unqualified; source edit undo continuity now has a passing browser regression test.
- Native URI activation, full attachment paste/drop and native long-document/1000-note performance qualification.
- Final native dependency/font/media license/SBOM/security review.

Known limitations are not silently moved to v0.2. `scripts/release-gate.mjs` rejects the missing native evidence; no tag or pre-release may be created while these blockers remain. Git is NotConfigured; remote sync, graph/canvas/bases/export/E2EE are planned later capabilities.

An additional resolver safety regression rejects a unique surviving quote in changed context instead of silently choosing it. The C# and TypeScript rules match; a focused real browser selection-link round-trip still passes. Link UUID text is canonical hyphenated form in both languages.
