# v0.1.0-alpha.1 acceptance — release blocked

This is an unreleased development delivery, not a completed native alpha. Environment: Debian 13 x64; .NET 10.0.403; Node 24.19.0; pnpm 12.16.1; Chromium headless shell 156.0.8078.4. Native OS/device: none. User confirmed no Windows/Android acceptance environment or durable Android signing setup is available.

Initial verified portable results: 25 xUnit tests, 36 Vitest tests and 6 Playwright integration tests passed. Later permission/API changes are under final regression verification; the final summary will replace these counts. Type checking, ESLint and Vite/SDK builds passed. npm audit after the two explicit overrides reports zero known vulnerabilities. Core NuGet vulnerability query returned no affected package entries. Portable license inventory recorded 419 restored packages, including specifically reviewed legacy xUnit license metadata. Native dependency/asset license qualification remains pending.

The browser suite uses real Markdown/Sidecar/SQLite storage. It verifies create/multiple notes, Unicode editing, autosave, file reload, search, SDK toolbar unload, exact-source three-second peek, unknown block-directive retention and confirmed clear. It is not native runtime evidence. Full test outputs remain in artifacts; no device or screenshot is fabricated.

Release blockers:

- Windows native build/run, actual WinUI/material/keyboard/accessibility and shutdown acceptance.
- Android build/install/run, Chinese IME/Emoji/long-press/keyboard/lifecycle and process-death acceptance.
- Durable Android release keystore, non-debug signing, verified installable assets and repeat-download checks.
- Complete nested block/heading folding coverage, live Yjs fallback integration and unambiguous repair UI.
- External Markdown/sidecar reconciliation UI, persistent workspace session and complete multi-pane workspace.
- Complete persistent plugin storage/object identity and externally built plugin installation acceptance.
- Markdown Peek apply/edit undo continuity; unsupported inline/HTML extensions remain conservatively read-only or unqualified.
- Native URI activation, full attachment paste/drop and native long-document/1000-note performance qualification.
- Final native dependency/font/media license/SBOM/security review.

Known limitations are not silently moved to v0.2. `scripts/release-gate.mjs` rejects the missing native evidence; no tag or pre-release may be created while these blockers remain. Git is NotConfigured; remote sync, graph/canvas/bases/export/E2EE are planned later capabilities.
